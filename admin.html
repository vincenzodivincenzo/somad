Lista de espera

Todo el que se apunta en la web aparece aquí. Cámbiale el estado cuando le escribas, apunta notas y exporta cuando quieras.

Falta conectar la base de datos

  1. Crea un proyecto gratis en supabase.com.
  2. SQL Editor → pega supabase/schema.sql del repo (cambiando la clave) → Run.
  3. Project Settings → API: copia la URL y la anon key y pégalas en “Textos y contacto”.
  4. Vuelve a entrar en el panel con la clave de lista de espera.

Mientras tanto, el botón de la web manda la solicitud por WhatsApp.

Reservas

Falta conectar la base de datos
